# Auto-discovery playbook — Shoplit Recommendations

> How this KB stays fresh. Local copy of the generic playbook, tuned for our sources.

## What we scan, when, and where it lands

| Source | Cadence | Lands in |
|---|---|---|
| Merged PRs in `shoplit/recommendations` | weekly | contributor file Deliverables (via `team-knowledge` brain) |
| Closed Linear tickets in REC project | weekly | contributor file Deliverables |
| Chat space `#shoplit-recs-team` — messages tagged [DECISION] or [BLOCKER] | weekly | contributor file Decisions/Blockers |
| New docs in team drive | weekly | contributor file Documents |
| Weekly retro notes | per-meeting | promoted to intake by EM |
| External research (curated) | quarterly | industry_landscape.md |
| Customer support themes | monthly | gotchas_and_tips.md if pattern emerges |

## Who runs the pass

`rwest` runs `/brain-ingest` + `/brain-moderate` every Monday morning. Roughly 30 min total. ICs help with intake review only when something needs domain expertise (e.g. modeling-specific claim).

## When auto-discovery is wrong

- New strategy commitments don't come from PRs — they come from rwest's offsites. Manual entry to `intake.md`.
- Cross-team partnership status — chat decisions are noisy. Confirm in writing with the partner team before publishing.
